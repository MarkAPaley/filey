LINUX

On Linux, filey uses the copies of ffprobe, mkvmerge, mkvpropedit and OpenSSL installed on your system; it does not include its own. (If Wine is installed, it can also run the Windows copies above.) About > Info shows which ones were found, and the command that installs any that are missing.

OpenSSL is needed to download show and episode lists. Practically every Linux desktop already has it. Only the OpenSSL runtime library is used, so "libssl-dev" is NOT needed. To install it if it is missing, at the Terminal prompt enter the line for your distribution:

  Ubuntu, Debian, Linux Mint, Zorin OS:  sudo apt install openssl
  openSUSE:                              sudo zypper install openssl
  Fedora:                                sudo dnf install openssl
  Arch Linux, Manjaro:                   sudo pacman -S openssl

ffprobe reads video details (resolution, codec, audio channels); mkvmerge and mkvpropedit read and update Matroska (.mkv) tags:

  Ubuntu, Debian, Linux Mint, Zorin OS:  sudo apt install ffmpeg mkvtoolnix
  openSUSE:                              sudo zypper install ffmpeg-tools mkvtoolnix
  Fedora:                                sudo dnf install ffmpeg-free mkvtoolnix
  Arch Linux, Manjaro:                   sudo pacman -S ffmpeg mkvtoolnix-cli
